# 🎵 媒体播放检测扩展 (Chrome)

一个浏览器扩展，自动检测和恢复网页中的音视频播放，支持 **Chrome**和**Firefox**。

![preview](/docs/preview.png)

## ✨ 功能特点

- **自动检测音视频播放：** 检查手动开启监控的标签页，恢复暂停的媒体（音频或视频）。
- **兼容多种网站：** 尤其针对视频网站（如哔哩哔哩）播放问题。
- **手动控制：** 点击扩展图标，可以手动开启或停止对特定标签页的跟踪。
- **去除遮罩：** 去掉一些提示登录的遮罩。

## 🚀 安装方法

### Chrome

1. 打开 **Chrome 浏览器（102 或更高版本）**，进入 `chrome://extensions/`。
2. 打开右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择 **chrome** 文件夹。

### Firefox

1. 应用商店搜索 `Check Media Playback` 下载插件.

## 🔧 使用方法

1. 安装后，扩展图标会出现在浏览器工具栏上。
2. 点击图标，在需要监控的音视频标签页右侧开启开关；关闭开关即可停止该标签页的监控。
3. 已开启监控的页面会每秒检查一次播放状态，如有暂停，会自动恢复播放。未开启监控的页面不会创建定时检查任务。
4. 关闭扩展弹窗后，已开启的监控继续运行，再次打开弹窗会显示当前实际任务。
5. 退出浏览器后，本次监控任务结束。重新打开浏览器时默认不监控，需要重新选择标签页并手动开启。

### 配置与运行状态

| 数据 | 关闭弹窗 | 退出并重新打开浏览器 |
| --- | --- | --- |
| CSS 选择器、遮罩规则、用户设置的偏好 | 保留 | 保留 |
| 正在监控的标签页、当前监控任务 | 继续运行 | 清空，等待手动开启 |
| 临时运行数据 | 随当前任务保留 | 清空 |

遮罩设置中的“启用”是会保留的用户偏好，仅在手动开启标签页监控后生效，不会自动启动监控。关闭标签页也会清理其任务；刷新或导航已监控的标签页时，仅在当前浏览器会话中继续监控。

升级旧版本时，会删除原先永久保存的标签页勾选状态，保留已配置的选择器和遮罩偏好。
